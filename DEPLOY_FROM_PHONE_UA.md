# Як це має працювати для власника з телефону

Ти не повинен запускати код на телефоні.

Правильний процес такий:

1. Код завантажують у GitHub.
2. Frontend підключають до Vercel.
3. Backend з Telegram webhook підключають до окремого сервера.
4. Підключають PostgreSQL.
5. Вставляють Telegram Bot Token у змінні сервера.
6. Встановлюють webhook Telegram.
7. Ти отримуєш посилання на Mini App / адмінку.
8. Далі ти працюєш тільки з телефону:
   - відкриваєш адмінку;
   - підтверджуєш бронювання;
   - керуєш зонами;
   - редагуєш карту;
   - додаєш офіціантів;
   - міняєш номер телефону;
   - міняєш посилання на меню.

## Що потрібно від тебе для запуску

- Telegram Bot Token від BotFather;
- номер телефону адміністратора;
- назва ресторану;
- посилання на меню;
- фото/логотип, якщо потрібно;
- доступ до GitHub/Vercel або розробник, який це підключить.

## Що не треба робити з телефону

- запускати Docker;
- запускати Node.js;
- налаштовувати PostgreSQL руками;
- писати код;
- працювати з терміналом.
