# Святкові фотографії MOLO

Ця папка призначена для завантаження фотографій святкових тем.

## Куди завантажувати

| Свято | Папка |
| --- | --- |
| Новий рік | `new-year/` |
| Різдво | `christmas/` |
| День закоханих | `valentines/` |
| Великдень | `easter/` |
| Гелловін | `halloween/` |
| 8 Березня | `march-8/` |

Повний шлях починається з:

`frontend/public/maps/themes/holiday/`

Наприклад, новорічне фото залу:

`frontend/public/maps/themes/holiday/new-year/hall.png`

## Назви фотографій

У кожній папці свята мають бути рівно 9 PNG-файлів з однаковими назвами:

| Назва файлу | Локація |
| --- | --- |
| `territory.png` | Територія |
| `waterfront.png` | Набережна ресторану |
| `hall.png` | Зал |
| `canopy.png` | Навіс |
| `gazebo.png` | Альтанки |
| `rotang.png` | Ротанг |
| `embankment.png` | Набережна |
| `glass-gazebo.png` | Скляна альтанка |
| `water-gazebo.png` | Альтанка на воді |

## Важливо

- Використовуйте тільки формат PNG.
- Назви файлів пишіть маленькими англійськими літерами, точно як у таблиці.
- Не додавайте пробіли, великі літери або додаткові цифри.
- Для всіх 6 свят потрібно 54 фотографії: 6 × 9.
- Титульна сторінка не використовує святкові фотографії.
- Службовий файл `.gitkeep` лише зберігає порожню папку в GitHub. Після завантаження фотографій його можна залишити або видалити.
