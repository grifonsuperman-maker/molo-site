# Підключення Syrve Cloud API

Пульт Директора підтримує перевірку API-доступу, вибір організації, безпечне збереження, повторну перевірку та відключення Syrve.

## Обов’язкове налаштування сервера

У production потрібно встановити окремий довгий випадковий секрет:

```env
SYRVE_CREDENTIALS_SECRET=replace-with-a-long-random-secret
```

Дані API-логіна шифруються на backend через AES-256-GCM. Повний логін після збереження не повертається у frontend.

## Обмеження першого етапу

Підключення підтверджує доступ до Cloud API та організації. Синхронізація столів, замовлень і статусів у цьому етапі не ввімкнена.

Дозволені лише HTTPS-адреси офіційних доменів `*.syrve.live` та `*.iiko.cloud`.
